# Ascii Ship Game

A game rendered fully in ASCII about sinking your enemy's ship first built using Python and Pygame.


## How to Play (Release - Windows Only)
1. Go to the [Releases](https://github.com/OggyWoppy36/Ascii-Game/releases) section. 
2. Download the `AsciiGame-v0.1.1.zip` file.
3. Unzip the file and run `main.exe` to play! (Note: Windows Defender may stop you from running it as I am not a verified publisher)

## How to Run from Source
1. Clone this repository.
2. Install dependencies:
   ```bash
   pip install pygame
3. Run the game:
   ```bash
   python main.py
