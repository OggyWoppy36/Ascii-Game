# Ascii Ship Game

A game rendered fully in ASCII about sinking your enemy's ship first built using Python and Pygame. You can move around and aim/shoot a cannonball currently.

## Controls:
- Left/Right Arrow Keys or A/D: Move left and right
- Left-Click and Drag: Move around aiming reticle
- Double Left-Click: Shoot cannonball


## How to Play (Release - Windows Only)
1. Go to the [Releases](https://github.com/OggyWoppy36/Ascii-Game/releases) section. 
2. Download the `AsciiGame-v0.1.1.zip` file.
3. Unzip the file and run `main.exe` to play!
4. If Windows Defender stops you from running it:
   - Click "More Info"
   - Then click "Run Anyway"

## How to Run from Source
1. Clone this repository.
2. Ensure you have python installed (version 3.15 recommended)
3. Install pygame:
   ```bash
   pip install pygame-ce
4. Run the game:
   ```bash
   python main.py
